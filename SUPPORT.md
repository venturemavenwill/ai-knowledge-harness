# Support

## Choose the right channel

- **Setup, usage, and design questions:** start a
  [GitHub Discussion](https://github.com/venturemavenwill/ai-knowledge-harness/discussions).
- **Reproducible defects:** open a
  [bug report](https://github.com/venturemavenwill/ai-knowledge-harness/issues/new?template=bug-report.yml).
- **Reusable missing knowledge or routing gaps:** open a
  [harness gap](https://github.com/venturemavenwill/ai-knowledge-harness/issues/new?template=harness-gap.yml).
- **Feature proposals:** open a
  [capability proposal](https://github.com/venturemavenwill/ai-knowledge-harness/issues/new?template=capability-proposal.yml).
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md) and report them
  privately.

Search existing issues, discussions, namespaces, and the generated `INDEX.md`
before opening a new thread.

## Include enough evidence

For technical help, include the operating system, Python and Git versions, the
exact command, redacted output, and the smallest reproduction. State whether an
AI tool produced or transformed any relevant command or evidence.

Never post credentials, tokens, customer data, private source code, personal
data, or material you cannot legally redistribute.

Support is community-maintained and provided on a best-effort basis. A clear,
reproducible report is more likely to receive a useful response.
